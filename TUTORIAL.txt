TUTORIAL SINGKAT GNOSIA (NODE.JS + MYSQL)
=========================================

1. JALANKAN DI LAPTOP (LOKAL)
-----------------------------
Pastikan MySQL sudah jalan dan buat database + user (sekali saja):
    sudo mysql -e "CREATE DATABASE IF NOT EXISTS gnosia CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER IF NOT EXISTS 'gnosia'@'localhost' IDENTIFIED BY 'gnosia'; CREATE USER IF NOT EXISTS 'gnosia'@'127.0.0.1' IDENTIFIED BY 'gnosia'; GRANT ALL PRIVILEGES ON gnosia.* TO 'gnosia'@'localhost'; GRANT ALL PRIVILEGES ON gnosia.* TO 'gnosia'@'127.0.0.1'; FLUSH PRIVILEGES;"

Lalu jalankan:
    cd /home/qhumy/Documents/gnosia
    ./start.sh

Buka http://localhost:5173

2. HOSTING DI HOSTINGER (NODE.JS WEB APPS + MYSQL)
--------------------------------------------------
Buat paket zip siap upload:
    npm run zip:hostinger

Panduan lengkap langkah demi langkah ada di: docs/DEPLOY-HOSTINGER.md
